## 🚀 Как это смотреть?

*   **📓 Jupyter Notebook (`.ipynb`)** — нажмите на ссылку. GitHub автоматически отрендерит документ прямо в браузере: вы увидите текст, код и графики.
*   **📄 PDF-отчёты (`.pdf`)** — классический вариант для чтения. Открывается прямо на сайте.
*   **💻 Код Maple (`.mpl` / `.mw`)** — текстовый файл (`.mpl`) открывается как обычный текст, а рабочий файл (`.mw`) можно скачать и запустить в программе Maple.
*   **📝 Код LaTeX (`.tex`)** — исходник для компиляции документа.
*   **🎬 Анимации (`.gif`)** — сами запускаются в браузере при просмотре страницы задания.

## 📂 Как всё устроено

Каждое задание — это отдельная папка. Внутри всё разложено по полочкам:

```text
Task_XX/
├── README.md           <-- Описание задачи и ссылки
├── Project/            <-- Готовый PDF-отчёт и Jupyter Notebook (.pdf, .ipynb)
├── Codes/              <-- Исходники LaTeX и Maple (.tex, .mpl, .mw)
└── images/             <-- Файлы анимаций (.gif)
```
