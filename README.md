# 📐 Методы оптимизации: Решения задач

Добро пожаловать в репозиторий с решениями задач по курсу «Методы оптимизации» (Математическая теория оптимальных процессов). 

Здесь собраны подробные отчеты, исходный код на LaTeX и интерактивные визуализации, построенные в **Maple**.

---

## 🚀 Как просматривать файлы?

Чтобы вам было удобно ориентироваться, вот краткая инструкция по форматам файлов в этом репозитории:

*   **📄 PDF-отчеты (`.pdf`)** — просто нажмите на ссылку в папке задания. GitHub откроет документ прямо в браузере.
*   **📝 Код LaTeX (`.tex`)** — можно просмотреть прямо на сайте. Если хотите скомпилировать, скачайте файл и загрузите в Overleaf.
*   **💻 Код Maple в текстовом виде (`.mpl`)** — открывается как обычный текст прямо на GitHub. Удобно для быстрого чтения кода.
*   **⚙️ Рабочий файл Maple (`.mw`)** — скачайте его и откройте в программе Maple, чтобы запустить анимации и проверить вычисления.
*   **🎬 Анимации (`.gif`)** — воспроизводятся автоматически прямо в окне браузера при прокрутке страницы задания.
