## 🚀 Как это смотреть?

Чтобы не путаться в файлах, вот короткая шпаргалка:

*   **📄 PDF-отчёты (`.pdf`)** — просто тыкай на ссылку в папке задания. GitHub откроет документ прямо в браузере, ничего скачивать не надо.
*   **📝 Код LaTeX (`.tex`)** — можно глянуть прямо на сайте. Если хочешь скомпилировать, скачай файл и закинь в Overleaf.
*   **💻 Код Maple текстом (`.mpl`)** — открывается как обычный текст. Удобно, если надо быстро прочитать логику, не запуская Maple.
*   **⚙️ Рабочий файл Maple (`.mw`)** — качай его и открывай в самой программе Maple, чтобы покрутить графики и проверить вычисления.
*   **🎬 Анимации (`.gif`)** — сами запускаются в браузере, когда листаешь страницу задания. Можно смотреть, как точка бежит по траектории, не открывая никакого софта.

## 📂 Как всё устроено

Каждое задание — это отдельная папка. Внутри всё разложено по полочкам:

```text
Task_XX/
├── README.md      <-- Описание задачи и графики
├── Project/       <-- Готовый PDF-отчёт
├── Codes/         <-- Исходники LaTeX и Maple (.tex, .mpl, .mw)
└── images/        <-- Файлы анимаций (.gif)
```
