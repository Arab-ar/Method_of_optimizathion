# Задача 7: Простейшая задача вариационного исчисления с подвижными концами (ПЗВИ)

**Условие задачи:**

$$
\int_0^{T_0}\!\bigl(x^2+\dot x^2-4x\sin t\bigr)\,dt - 2x(T_0)+2x^2(0)-x^2(T_0)\to\text{extr}
$$

**Ответ:** Найдена единственная экстремаль $\hat x(t)$, доставляющая строгий глобальный минимум функционала.

## 📊 Краткое описание решения

*   **Уравнение Эйлера–Лагранжа:** $L = x^2+\dot x^2-4x\sin t \Rightarrow \ddot x - x = -2\sin t$. Общее решение: $x(t) = C_1 e^t + C_2 e^{-t} + \sin t$.
*   **Условия трансверсальности:** Для свободных концов $x(0)$ и $x(T_0)$ с граничным функционалом $\Phi = 2x^2(0) - 2x(T_0) - x^2(T_0)$ получаем $\dot x(0) = 2x(0)$ и $\dot x(T_0) = 1 + x(T_0)$.
*   **Нахождение констант:** Из условий трансверсальности однозначно находим $C_1, C_2$ через $T_0$ (деление только на $e^{-T_0}>0$, особых случаев нет).
*   **Условие Лежандра:** $L_{\dot x\dot x} = 2 > 0$ на $[0, T_0]$ — усиленное условие выполнено.
*   **Уравнение Якоби:** $\ddot h - h = 0$, $h(t) = \sinh t$. Единственный нуль $t=0$ вне $(0, T_0]$ — сопряжённых точек нет, условие Якоби выполнено.
*   **Условие Вейерштрасса:** $\mathcal{E} = (u-\dot x)^2 \ge 0$ с равенством только при $u = \dot x$ — усиленное условие выполнено $\Rightarrow$ сильный локальный минимум.
*   **Глобальность:** Положительная определённость второй вариации доказана через тождество Ньютона–Лейбница и неравенство $2ab \le a^2+b^2$: $\delta^2 J[h] \ge h^2(0) \ge 0$ (равенство только при $h \equiv 0$) $\Rightarrow$ строгий глобальный минимум.
