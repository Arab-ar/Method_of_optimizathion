# Задача 7: Простейшая задача вариационного исчисления с подвижными концами (ПЗВИ)

**Условие задачи:**

$$
\int_0^{T_0}\!\bigl(x^2+\dot x^2-4x\sin t\bigr)\,dt - 2x(T_0)+2x^2(0)-x^2(T_0)\to\operatorname{extr}
$$

**Ответ:** Найдена единственная экстремаль $\hat x(t)$, которая доставляет строгий глобальный минимум функционала.

## 📊 Краткое описание решения

Решение проводится по стандартному алгоритму для ПЗВИ с подвижными концами:

1. **Уравнение Эйлера–Лагранжа.** Составляется подынтегральная функция $L = x^2+\dot x^2-4x\sin t$. Записывается необходимое условие экстремума $-\frac{d}{dt}L_{\dot x}+L_x=0$, которое сводится к линейному неоднородному ОДУ второго порядка $\ddot x - x = -2\sin t$. Общее решение: $x(t) = C_1 e^t + C_2 e^{-t} + \sin t$.

2. **Условия трансверсальности.** Поскольку концы $x(0)$ и $x(T_0)$ свободны, а граничный функционал $\Phi = 2x^2(0) - 2x(T_0) - x^2(T_0)$, записываются два условия трансверсальности: $\dot x(0) = 2x(0)$ и $\dot x(T_0) = 1 + x(T_0)$. Из них однозначно находятся константы $C_1$ и $C_2$ через параметр $T_0$. Деление происходит только на $e^{-T_0} > 0$, особых случаев нет.

3. **Условия второго порядка.** 
   * *Условие Лежандра:* $L_{\dot x\dot x} = 2 > 0$ на всём $[0, T_0]$ — выполнено усиленно.
   * *Уравнение Якоби:* Сводится к $\ddot h - h = 0$. Решение $h(t) = \sinh t$ имеет единственный нуль в точке $t=0$, которая лежит вне интервала $(0, T_0]$. Сопряжённых точек нет при любом $T_0 > 0$ — условие Якоби выполнено.
   * *Условие Вейерштрасса:* $\mathcal{E}$-функция вычисляется напрямую: $\mathcal{E} = (u - \dot x)^2 \geq 0$. Равенство достигается только при $u = \dot x$ — условие Вейерштрасса выполнено. Экстремаль доставляет сильный локальный минимум.

4. **Глобальность минимума.** Стандартная теорема о глобальном минимуме через выпуклость неприменима (граничный функционал $\Phi$ не выпукл по $x(T_0)$, так как $\Phi_{x(T_0)x(T_0)} = -2 < 0$). Вместо этого положительная определённость второй вариации $\delta^2 J[h] = \int_0^{T_0}(h^2+\dot h^2)\,dt + 2h^2(0) - h^2(T_0)$ доказывается напрямую через тождество Ньютона–Лейбница и неравенство $2ab \leq a^2+b^2$: отрицательный член $-h^2(T_0)$ поглощается интегралом $\int(h^2+\dot h^2)\,dt$, и остаётся $\delta^2 J[h] \geq h^2(0) \geq 0$ с равенством только при $h \equiv 0$. Поскольку функционал квадратичен, это даёт строгий глобальный минимум.
