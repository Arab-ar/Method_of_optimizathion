# Задача 7: Задача Больца

**Условие задачи:**

$$
\mathcal{B}(x(\cdot))=\int_0^{T_0}\\bigl(x^2+\dot x^2-4x\sin t\bigr)dt + l(x(0),x(T_0))\to\text{extr}
$$

где $l(x_0,x_1)=2x_0^2-2x_1-x_1^2$.

**Ответ:** Найдена единственная экстремаль $\hat x(t)$, доставляющая строгий глобальный минимум функционала Больца.

## 📊 Алгоритм решения

*   **Уравнение Эйлера:** $L = x^2+\dot x^2-4x\sin t \Rightarrow \ddot x - x = -2\sin t \Rightarrow x(t) = C_1 e^t + C_2 e^{-t} + \sin t$.
*   **Условия трансверсальности:** $l_{x_0}=4x_0$, $l_{x_1}=-2-2x_1 \Rightarrow \dot x(0)=2x(0)$, $\dot x(T_0)=1+x(T_0)$.
*   **Константы:** Из условий трансверсальности находим $C_1, C_2$ через $T_0$ (без особых случаев).
*   **Условие Лежандра:** $L_{\dot x\dot x} = 2 > 0$ — выполнено усиленно.
*   **Уравнение Якоби:** $h(t) = \sinh t$, нулей на $(0, T_0]$ нет — выполнено.
*   **Условие Вейерштрасса:** $\mathcal{E} = (u-\dot x)^2 \ge 0$ — выполнено $\Rightarrow$ сильный локальный минимум.
*   **Глобальность:** $\delta^2 \mathcal{B}[h] \ge h^2(0) \ge 0$ (равенство только при $h \equiv 0$) $\Rightarrow$ строгий глобальный минимум.
