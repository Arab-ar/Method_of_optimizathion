# Задача 7: Простейшая задача вариационного исчисления с подвижными концами (ПЗВИ)

**Условие задачи:**

$$
int_0^{T_0}\!\bigl(x^2+\dot x^2-4x\sin t\bigr)\,dt - 2x(T_0)+2x^2(0)-x^2(T_0)\to\operatorname{extr}
$$

**Ответ:** Найдена единственная экстремаль $\hat x(t)$, доставляющая строгий глобальный минимум функционала.

## 📊 Краткое описание решения

*   **Экстремаль:** Уравнение Эйлера $\ddot x - x = -2\sin t$ дает общее решение $x(t) = C_1 e^t + C_2 e^{-t} + \sin t$.
*   **Трансверсальность:** Условия для свободных концов $x(0)$ и $x(T_0)$ однозначно определяют константы $C_1, C_2$ при любом $T_0 > 0$ (без особых случаев).
*   **Достаточные условия:** Усиленные условия Лежандра ($L_{\dot x\dot x}=2>0$), Якоби ($h(t)=\sinh t$ не имеет нулей на $(0, T_0]$) и Вейерштрасса ($\mathcal{E}=(u-\dot x)^2 \ge 0$) выполнены $\Rightarrow$ сильный локальный минимум.
*   **Глобальность:** Из-за невыпуклости граничного функционала глобальный минимум доказан напрямую через положительную определенность второй вариации: $\delta^2 J[h] \ge h^2(0) \ge 0$ (с равенством только при $h \equiv 0$).
